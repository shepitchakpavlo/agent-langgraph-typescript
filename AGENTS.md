# Project Context: LangGraph Research Agents (Modern Features)

This project is a TypeScript-based implementation of a multi-agent research system using **LangGraph**. It demonstrates modern LangGraph features like `ToolNode`, structured output, and persistent memory.

## Project Overview
The application uses **LangGraph** to orchestrate a research workflow:
1.  **Research Agent**: Analyzes the user's topic and decides which search queries to execute using the `web_search` tool.
2.  **ToolNode**: Executes the tool calls generated by the Research Agent.
3.  **Summarization Agent**: Synthesizes the search results into a structured JSON summary.

### Core Technologies
- **TypeScript**: Main programming language.
- **LangGraph (@langchain/langgraph)**: Orchestration framework.
- **LangChain (@langchain/openai, @langchain/core)**: Used for LLM interaction and message schemas.
- **OpenRouter**: Used as the API gateway to access `openai/gpt-4o-mini`.
- **Yarn PnP**: The project uses Yarn Plug'n'Play for dependency management.

## Architecture and Workflow
The workflow is defined in `src/graph.ts` using a `StateGraph`.

### Modern Features Implemented
- **ToolNode for Execution**: Instead of manual loops, the graph uses `ToolNode` and `toolsCondition` to handle tool calls.
- **Structured Output**: The Summarization Agent uses `.withStructuredOutput()` to produce a typed JSON object defined by a Zod schema.
- **Memory & Human-in-the-Loop**: The graph is compiled with a `MemorySaver` checkpointer, allowing for state persistence across sessions using a `thread_id`.

### Graph Structure
- **Nodes**: `researchAgent`, `tools` (ToolNode), `summarizationAgent`.
- **Edges**: 
  - `START` -> `researchAgent`
  - `researchAgent` -> `tools` (if tool calls are present)
  - `tools` -> `researchAgent` (loop back for further research)
  - `researchAgent` -> `summarizationAgent` (if no tool calls)
  - `summarizationAgent` -> `END`

## Key Files
- `src/index.ts`: Entry point with `app.invoke` and thread configuration.
- `src/graph.ts`: Workflow definition with nodes and conditional edges.
- `src/state.ts`: State definition using `Annotation.Root`.
- `src/nodes/`: Agent implementations.
- `src/tools/`: Tool definitions (e.g., `webSearch`).
- `src/schemas/`: Zod schemas for structured output.

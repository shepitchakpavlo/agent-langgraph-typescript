# Project Context: LangGraph Sequential Agents

This project is a TypeScript-based implementation of a sequential multi-agent system using **LangGraph**. It demonstrates a linear workflow where one agent's output serves as the input for another.

## Project Overview
The application uses **LangGraph** to orchestrate two agents:
1.  **Agent 1 (Story Writer)**: Generates a short story (2-3 sentences) based on a user-provided topic.
2.  **Agent 2 (Summarizer)**: Summarizes the story produced by Agent 1.

### Core Technologies
- **TypeScript**: Main programming language.
- **LangGraph (@langchain/langgraph)**: Orchestration framework for the agent workflow.
- **LangChain (@langchain/openai, @langchain/core)**: Used for LLM interaction and message schemas.
- **OpenRouter**: Used as the API gateway to access `google/gemini-2.0-flash-lite-001`.
- **Yarn PnP**: The project uses Yarn Plug'n'Play for dependency management.

## Building and Running

### Development
To run the project in development mode using `ts-node`:
```bash

```

### Production
To build and run the compiled JavaScript:
```bash
yarn build
yarn start
```

### Type Checking
To check for TypeScript errors without emitting files:
```bash
yarn tsc --noEmit
```

## Architecture and Workflow
The workflow is defined in `src/index.ts` using a `StateGraph`.

### State Management
The `AgentStateAnnotation` defines the shared state:
- `messages`: A list of `BaseMessage` objects (history).
- `userInput`: The initial topic provided by the user.
- `agent1Output`: The story generated by Agent 1.
- `agent2Output`: The summary generated by Agent 2.

### Graph Structure
- **Nodes**: `agent1`, `agent2`.
- **Edges**: `START` -> `agent1` -> `agent2` -> `END`.

## Development Conventions
- **State Reducers**: The `messages` state uses a reducer to concatenate new messages to the existing history.
- **Environment Variables**: API keys and base URLs are managed via a `.env` file (processed by `dotenv`).
- **Modern LangGraph API**: Uses the `Annotation.Root` and `Annotation` API for state definition.
- **Model Choice**: Defaulted to `google/gemini-2.0-flash-lite-001` via OpenRouter for cost-efficiency.

## Key Files
- `src/index.ts`: The entry point containing the agent logic, graph definition, and execution loop.
- `package.json`: Contains project dependencies and scripts (`build`, `start`, `dev`).
- `tsconfig.json`: Configured for `ES2020` and `CommonJS` output.
- `.env`: Holds the `OPENROUTER_API_KEY` and optional `OPENROUTER_BASE_URL`.
- `.yarn/sdks`: Contains Yarn PnP SDKs for editor support (e.g., TypeScript wrapper).
